# 目的・KPI設計

## 1. 目的（Purpose）
本システム（製品資料 自動抽出エンジン）は、見積書CSVなどの製品リストデータから、関連する製品資料（PDF・PPTX）をS3等のストレージから自動検索・抽出し、単一の結合ファイルとしてユーザーに提供することを目的とします。
従来の手作業による資料収集・結合の手間を削減し、営業活動や提案業務の生産性を大幅に向上させます。

## 2. KPI設計（Key Performance Indicators）

### 重要指標
- **資料作成時間の短縮率**: 現状かかっている資料収集・結合の作業時間を比較し、80%以上の削減を目指す。
- **資料抽出成功率**: 入力されたCSV（各種フォーマット）からの製品品番の認識率およびS3からの資料取得成功率95%以上。
- **システム利用回数（MAU / WAU）**: 営業・提案担当者による実際のシステム利用頻度。

### サブ指標
- 複数フォーマットのCSV処理エラー率
- ドキュメントのマージ（PDF/PPTX）における失敗・エラー件数
