# 機能一覧（バックログ）

## 1. 主要機能モジュール

### a. CSV入力・解析機能
- 複数CSVフォーマットの自動識別機能
- CSVデータの正規化機能
- 製品ID（品番）の抽出

### b. 資料検索・抽出機能 (S3連携)
- S3からのファイルリスト取得・検索機能
- 品番に基づくPDFファイル／PPTXファイルへのマッチング処理
- ファイルの自動ダウンロード処理

### c. ドキュメント結合・プレビュー機能
- PDFファイルの自動マージ機能
- PPTXファイルの自動マージ機能
- 抽出結果（プレビュー）の画面表示

### d. UI/UX 機能
- CSVファイルアップロードパネル
- マッチ状況画面（一致リスト、不一致リスト、重複リストの表形式表示）
- 結果のサマリーカード表示
- S3プレフィックスの指定・選択機能
