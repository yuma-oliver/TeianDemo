# ユーザーストーリー（要求定義）

## ペルソナ
- **営業担当者**: 見積書を作成し、それに関連する製品のカタログや提案資料を顧客に提出する。
- **業務アシスタント**: 多数の製品資料を社内ストレージやS3から探し出し、1つの資料にまとめている。

## ストーリー一覧

| No | ユーザー（Who） | ストーリー（What/Why） | 優先度 |
|---|---|---|---|
| US-01 | 営業担当者 | 多様なフォーマットの見積もりCSV（レガシー/新規）をそのままシステムにアップロードしたい。CSVフォーマットを意識せずに製品リストをシステムに読み込ませるため。 | 高 |
| US-02 | 業務アシスタント | 指定した製品リストに関連する提案資料(PDF)や製品資料(PPTX)を自動で抽出し、ダウンロードしたい。手動で検索する手間を省くため。 | 高 |
| US-03 | 営業担当者 | マージされたPDFおよびPPTXファイルをプレビューし、結果を確認してから出力したい。誤った資料が混ざっていないかチェックするため。 | 中 |
| US-04 | 業務アシスタント | S3上にある特定のフォルダ階層から対象ファイルを探せるようにプレフィックス等を指定したい。資料のバージョンやカテゴリを区別するため。 | 高 |
| US-05 | 営業担当者 | マッチしなかった（資料がS3に見つからなかった）製品の一覧を画面上で確認したい。不足している資料を手動で補うため。 | 高 |
